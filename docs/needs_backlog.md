## Pain points from research & comments (2026-11)
- Fully booked / reservation-only vs walk-in confusion → walk-in roundups, "no reservations" flag
- Long queues → when to go (before 12 / after 1pm), sell-out timing
- Luggage in tiny counters → (need data: seats count exists for some)
- Allergies / vegetarian / halal → allergy card exists in the free guide's phrase page; only 2 veg/halal entries in DB, so research before promising
- "Open" ≠ last order, late-night varies → done (h_07, c_08)
- Comment asks: "Spots please", "where is this?", "locals", prices, kids → always name the place, station, price, and a kids/smoking note
